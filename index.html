¿Qué es Winget?

Winget (Windows Package Manager) es una utilidad de línea de comandos de código abierto que permite descubrir, instalar, actualizar, eliminar y configurar aplicaciones en dispositivos Windows 10 y Windows 11. Es el equivalente en Windows a herramientas como apt en Ubuntu o Homebrew en macOS.

Instalación de Winget

Winget suele venir preinstalado en las versiones modernas de Windows 10 y 11 como parte del Instalador de Aplicaciones de Microsoft Store. Si no lo tienes, puedes instalarlo así:

  • Descargando el paquete desde la página de lanzamientos de Winget CLI en GitHub.
  • Actualizando la aplicación Instalador de Aplicaciones desde la Microsoft Store.

Verificar la instalación

Comprueba que Winget está disponible y consulta su versión.

winget --version

Comandos básicos

Buscar paquetes

Busca aplicaciones disponibles en los repositorios (orígenes) configurados en Winget.

winget search

Instalar un paquete

Instala una aplicación específica desde el origen predeterminado.

winget install

Mostrar detalles de un paquete

Obtiene información detallada sobre un paquete: versión, editor, descripción y página de inicio.

winget show

Actualizar paquetes

Actualiza una aplicación instalada o, con --all, todas las que Winget puede gestionar.

winget upgrade 
winget upgrade --all

Desinstalar un paquete

Elimina una aplicación instalada previamente con Winget o detectada en el sistema.

winget uninstall

Listar paquetes instalados

Muestra todas las aplicaciones instaladas y cuáles tienen actualizaciones disponibles.

winget list

Comandos avanzados

Gestionar orígenes (source)

Lista, añade o elimina repositorios de paquetes adicionales.

winget source list
winget source add --name  --arg 
winget source remove --name

Generar hash de paquete

Calcula el hash SHA256 de un instalador, necesario para crear manifestos de paquetes.

winget hash

Configurar Winget

Abre el archivo de configuración settings.json para personalizar orígenes, comportamiento y visualización.

winget settings

Exportar e importar paquetes

Exporta la lista de aplicaciones instaladas a un JSON o restaura esa lista en otra máquina.

winget export -o paquetes.json
winget import -i paquetes.json

Opciones comunes

Estas opciones pueden combinarse con install, upgrade, uninstall y otros comandos:

--id
Identifica el paquete por su identificador único (más preciso que el nombre).
--exact
Exige coincidencia exacta con el nombre o id indicado (sin búsqueda difusa).
--silent
Instala sin interfaz gráfica del instalador (modo desatendido).
--scope
Define el ámbito de instalación: user (usuario) o machine (todos).
-e / -h
Forma corta de --exact y --silent respectivamente.

Ejemplos prácticos

Buscar VLC Media Player

Encuentra el paquete de VLC en el origen predeterminado.

winget search VLC

Instalar Visual Studio Code

Instalación silenciosa identificando el paquete por su id exacto.

winget install --id Microsoft.VisualStudioCode --exact --silent

Actualizar todas las aplicaciones

Actualiza todo el software gestionado por Winget en modo desatendido.

winget upgrade --all --silent

Desinstalar por id exacto

Elimina VLC indicando su identificador único para evitar ambigüedades.

winget uninstall --id VideoLAN.VLC --exact

Solución de problemas

«El término winget no se reconoce»
Actualiza el Instalador de Aplicaciones desde la Microsoft Store o instala Winget desde GitHub releases.
Error al instalar por nombre ambiguo
Usa --id --exact para acotar el paquete.
Falla la actualización de un paquete
Ejecuta winget upgrade --include-unknown para incluir versiones desconocidas.
El comando es demasiado lento
Comprueba el origen con winget source list y elimina los que no necesites.
